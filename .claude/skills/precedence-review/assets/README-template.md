**Terms:**
- **Relationship:** same technique (reused essentially intact); adapted (structure followed, core changed); fragment (one piece reused); same route (an earlier paper proposed the strategy); same result; weaker result (weaker, special-case or partial-range); subsuming result (a published result would replace much of the argument).
- **Centrality** (best-effort): main result (the earlier work covers the main result itself, or most of it); central (the main theorem's proof runs through it); supporting (it feeds a central step); peripheral.
- **Attribution gap:** a close relationship, at least supporting, with the earlier work not cited for this content anywhere.
- **Overstated novelty:** the earlier work is cited for this content, but the abstract or framing presents it as new.
